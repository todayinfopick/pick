# pick (실행·링크 페이지 저장소)

이 공개 저장소는 **실행과 링크 페이지만** 맡습니다. 프로그램 코드는 비공개 저장소 `todayinfopick/pick-app`에 있습니다.

- `.github/workflows/` — 자동 게시·블로그·exe 만들기. 실행할 때마다 `pick-app`에서 코드를 꺼내 와서(비밀값 `CODE_TOKEN`) 돌립니다.
- `posted.json`, `research.json`, `ai_drop.json`, `photo_exclude.json`, `추가상품.csv` — 게시 기록과 데이터
- `docs/` — 링크 페이지 (todayinfopick.github.io/pick/)
- 릴리스 `app` — PC 프로그램(CoupangAutopost.exe)과 크롬 확장 묶음

**코드는 여기에 올리지 마세요.** 코드 수정은 `pick-app`에서 합니다.
